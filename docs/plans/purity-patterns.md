# Patterns: commonalities, differences, new hypotheses — 2026-09-08

Control (veto): Gives bread / Forgives on asking / Doesn't tempt / Loves enemies /
Known via Son. Full matrices in session artifacts; condensed here.

## 1. Commonalities (8 motifs, shared SHAPE)

- Waters/deep: tehom/Chaos/Apsu-Tiamat/Nun — all start unformed watery dark.
  Genesis outlier: non-combat fiat ("and-it-was-so… good").
- Council: Olympus / Milky-Way session / senate-graded fate / Anshar feast /
  42 assessors / bene elohim / premortal noble ones — seated hosts, speech +
  assent, judgment downward. Genesis outlier: servant-court, no faction veto.
- Flood + remnant: corruption → grief/anger → water → one household + mountain
  → altar → repopulation. Genesis outlier: grief + covenant, not revenue loss.
- Giants/heroes: god×human unions → violent offspring → bound/slain.
  Genesis outlier: human-guilt fork (Moses 8 Sethite breach vs Shemihazah
  determinism vs Asael tech strand).
- Hospitality: disguised visit → meal → vessel miracle → revelation + judgment
  on neighbors → host rewarded. Genesis outlier: intercession (Abraham bargains;
  no pagan intercessor found on shelf).
- Underworld: descent → gate/river → judge + records → sorted regions →
  name-knowledge passport. Genesis outlier: no tolls, no purgation pricing,
  advocate + return offered.
- Sun/chariot: charioted all-seeing judge, herds, oath by light, gate of dead.
  Genesis outlier: unnamed lamps, refused cult; order kept, worship refused.
- Tree/wisdom: central tree gives life/sight; anointing oil/fruit; Lady behind
  tree; rival death-tree. Genesis outlier: Life intended, Fall out-of-order
  seeking, reversible via veil/atonement.

## 2. Differences (6 ethic vectors; + aligned, ~ mixed, - violating)

vs 42 name-passwords + silencing spell); judgment Genesis vs Book of Dead
(advocate vs Amemit); giving Genesis vs Ovid (bread freely vs trap/withheld).

## 3. New-pattern verdicts

- H1 HOSPITALITY INVERSION — HOLDS as tendency. Lycaon trap-test (Ovid I),
  Baucis mass-drowning with no intercessor (Ovid VIII), suitors slaughtered
  (Odyssey) vs Abraham meal + bargaining, Lot dragged out, Emmaus/3 Ne 18
  meals. Falsifier: one forgiving pagan intercessor, or one non-bargained
  Genesis collective punishment.
- H2 BREAD VECTOR — PARTIAL. Enuma blood→service upward; Gilgamesh bread as
  ascent-price; Duat eternal farm to feed gods; manna/Lord's Prayer given.
  Leaks: Ani "given bread to hungry" confession + Baucis goblet. Not cleanest
  separator alone — pair with intercession.
- H3 VEIL/ASCENT — PARTIAL. Barker: veil = earth/heaven boundary; entrants
  transformed (2 En 22, Zech 3, Moses shining face). Supports transfiguration
  mechanism for Ex 33:11 vs 33:20. Gap: disguised-descent/linen specifics and
  Ex 33 reconciliation not on shelf (Heiser two-Yahwehs alternate resolution).
- H4 ENVOY TYPE-SCENE — PARTIAL. Mahijah question (Moses 6:40) + Mahujah place
  (7:2) + Mahawai twice-sent with two dreams (4Q530) + maḫḫû messenger class
  (Mari). Fit inexact: identity-question vs dream-interpretation; Joseph/Daniel
  collation still needed for "stable ANE" claim.
- H5 STATIONS NOT SIGNS — HOLDS as control. Steele: uniform 12×30° zodiac late
  5th c., threshold ~400 BCE → Job/Amos/Kings terms are MUL.APIN stations.
  Iconography-not-astrology corollary for 2 Kgs 23 inventory: plausible,
  underdetermined (mazzaloth text itself not on shelf).
- H6 EVIL ORIGINS TRAJECTORY — HOLDS directionally. Watcher-determinist
  (humans unmentioned) vs Genesis-responsibility (disobedience) with Jubilees
  re-balance middle and Moses 8 return-to-responsibility end. Middle/end
  loci thin on shelf — flagged.

## 5. Anderson-antidote (new)

Pagan gods test to punish (Lycaon trap, Baucis drowning, suitors slaughter);
YHWH in Gen 18 lets a man bargain Him down and drags Lot out. A tester-god who
submits to intercession is the opposite of the accuser pattern — directly
counters "Yahweh = tester = Satan" from inside the text, no JST needed.
