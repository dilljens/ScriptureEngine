# EDITORIAL — ScriptureEngine essays

House rules live in `/home/dillon/_code/ai-practice/editorial-standard.md`. This sheet records what this project does differently, and why.

## 1 · Audience

Readers are Latter-day Saint students seeking sanctification, not academics. They own KJV vocabulary, Nephi's keys (2 Ne. 25:1-8), Christ's command (3 Ne. 23:1-3), D&C presence promises. They do NOT own Hebrew transliteration, form-critical terms (Gunkel, Mowinckel), or source-critical debates. Forwarded to friends, family, ward members with no prior context.

Borrowed vocabulary check: `qadosh, tahor, kavod, panim, shuv, kaphar` are jargon unless defined where first met, not glossary-only. Keep transliteration + one-line gloss on first use.

AI-drafted prose can ship disclosed, but claimed-authorship pieces must sound like the author. Keep working notes in note form.

## 2 · Suspensions

None yet. Inverted pyramid governs at document and section level. No tables in spoken versions only; essays may use tables sparingly.

## 3 · Local rules

- **No em-dash** (James 2026-08-10): em dashes read as AI-written. Use stop, comma, colon, semicolon, or parens. Each needs right substitute, not find-replace. Applies to all 7 essays (436 instances, 2026-09-16).
- **US spelling** throughout, never inside verbatim KJV quotation.
- **BLUF openings**: every essay and every `##` section opens on its own conclusion. One rapid reading must carry claim. Truncation test: cut off anywhere, remainder is most important part.
- **No-color**: every sentence carries distinct claim. No restatement, no commentary on argument, no unneeded clarification.
- **Hebrew terms**: define where first met (`Holiness (qadosh) means set apart`), not glossary-only. Proposed chiasms labeled proposed unless demonstrated.
- **Citations**: `:verse[]` markers for scripture; Baker-Ricks / Morales / Nibley claims marked as proposal/lens, not settled fact. Copyrighted work cited via authorized sampler + print consult note.
- **Companion framing**: essays state companion relationship up front (`Companion to "Ascending to Presence"`), standalone summary tested standalone (forwarding test).
